# rb-website

Personal portfolio website for Ricardo Bizerra, built with Next.js App Router, React 19, TypeScript, Tailwind CSS v4, and shadcn/ui.

## Getting Started

Prerequisites: Node.js 22+ and `pnpm`.

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000` in your browser.

## Validation Commands

```bash
pnpm typecheck
pnpm lint
pnpm build
pnpm docs:check
```
